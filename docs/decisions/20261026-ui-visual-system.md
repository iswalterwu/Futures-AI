# D-011 UI 视觉体系与交互形态

- 日期：2026-10-26
- 状态：accepted

## 背景

产品形态视觉工作流（浏览器 mockup 会话）逐项确定工作台、对话与视觉体系的关键形态。

## 结论

1. **首页 = 工作台 + 今日焦点带**（C 布局）：打开即模块工作台，顶部焦点带承载当日日报核心结论，点击展开完整日报
2. **左侧菜单**：工作台 · 日报 · 价格 · 平衡表 · 物流 · 专题研究 · 知识库 · 设置；随用户新增研究动态扩展
3. **AI 对话**：底部输入栏向上展开为抽屉；CoT 用时间线呈现、每步可展开推理；运行中用户可切走页面，agent 后台执行
4. **AI 提示标记**：对应模块角标（badge）
5. **主色调**：暗色玻璃——近黑暖灰底 + 玻璃层级（面 3–6% 白透明 + 高模糊、边 7–14% 白描边）
6. **涨跌颜色**：行情模块红涨绿跌（涨 = 茹藘红亮化 `#C98A8F`、跌 = 缥碧亮化 `#8FB8A4`）；分析图表保持红 = 负（FTEngine 语义），边界以模块划分
7. **模块系统**：模块库选择 + 固定栅格（不做自由拖拽）
8. **墨 + 黛驼暗色适配**：墨 `#16191D` 转背景基调，黛驼灰系转亮色文字/表面/序列线（细则见 designUI.md）

## 取舍理由

- 工作台 + 焦点带：兼顾盯盘数据密度与每日认知，日报退为侧栏页面
- 暗色玻璃：符合"黑白灰阶、高质感、professional"的产品描述；玻璃层级限制三层（焦点带/模块/抽屉），防层级失控
- 红涨绿跌只限行情模块：保住中国交易者直觉，同时守住 FTEngine 分析图表色语义
- 模块库 + 固定栅格：实现成本低、视觉稳定；自由拖拽留给 v2 自定义能力再评估
