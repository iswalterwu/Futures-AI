# D-016 双循环交互架构：作业对象、四阶段契约与介入机制

- 日期：2026-10-28
- 状态：accepted
- 关系：补充 D-011 结论 1（工作台增加作业轨道）；变更 D-011 结论 2（左侧菜单 8 项 → 9 项）；调整 D-011 结论 3 的产品地位（对话为接口之一，视觉形态不变）；D-011 结论 4–8 的原有语义保留（角标扩展见 `designUI.md` §3.9）
- 相关：`plan.md` §2/§3/§8、`architecture.md` §1/§2/§4.4/§4.6/§5.4/§6、`designUI.md` §1/§2.4/§3/§5.2/§6/§7/§8、`docs/interaction.md`（权威）、D-017

## 背景

现有定位是"每天产出图表 + 日报的 AI 分析软件"：四阶段全自动、对话是唯一 AI 入口、交付完成即结束。市场三类产品——对话优先型、副驾型、检索终端型——共同缺三件事：**人的介入不是一等数据、交付物不是下一轮问题的生成器、知识回流没有闸门**。

2026-10-28 Walter 确认：产品应同时具备工作交付与学习的自迭代工作流；用户应能在任意阶段介入但不干扰；交付物应生成"验证性需求"驱动下一轮采集；学习应作为独立工作区由用户发起。该判断改变产品的主导对象与循环结构，属于架构级决策。

## 备选方案

- **A（采纳）**：以"作业"为一等对象，四阶段各设介入界面；人走旁路介入、产物版本化、检查点合并；交付物按块编辑与版本发布，发布后抽取验证性需求；学习循环独立成区；全部共享带谱系的知识底座与分析协议
- B 维持现定位，仅把交付物做成可编辑文档：改动小，但人的介入只覆盖交付阶段，数据处理/分析阶段仍无接口，交付物也不产生下一轮问题
- C 纯对话优先，把阶段操作全部压进对话：无法可靠定位"改哪一块/哪一阶段"，无法承载版本、溯源与检查点，否决

## 结论

1. 定位更新为 **Agent+人 双循环工作台**：交付循环（提取 → 处理 → 分析 → 交付 → 验证性需求 → 新作业）+ 学习循环（用户发起 → 阅读/复盘/深挖 → 认知产物 → 回流），两者共享知识底座与分析协议（`interaction.md` §2）
2. **作业（Work）** 为一等对象：有阶段、版本、参与者（人/agent）与状态机；对话降为接口之一；模块工作台负责"看"、作业负责"做"（`interaction.md` §2.4）
3. 四阶段各定义**阶段契约**与介入界面；人的介入走**旁路**——不阻塞 agent、不覆盖产物、在检查点合并，冲突不阻塞流程（`interaction.md` §3.2–3.3）
4. 介入**事件化**：结构化记录类型、作用域、依据与结果，作为分析协议蒸馏的原料（`interaction.md` §3.4、§6）
5. 交付物为**块式、版本化活文档**：块类型与块模型见 `designUI.md` §5.2；发布为不可变快照；人可编辑、块批注、下指令改稿（`interaction.md` §3.5）
6. 交付完成后抽取四类**验证性需求**（延展采集 / 证据追踪 / 假设验证 / 反证搜索）；用户确认后生成新作业与**采集计划**（主动 / 定时 / 事件触发），监测到变化生成增量版本（`interaction.md` §3.6）
7. **学习区** 为用户发起的第二工作区：信息密集、无固定交付模板，以认知增量衡量；产物回流知识底座（`interaction.md` §4）
8. **三层自迭代**：L1 产物（版本 / 重跑）、L2 协议（介入 → 分析协议）、L3 知识（写入闸门 + 断言台账 + 验证性需求）；以一次通过率、人改率等指标验收（`interaction.md` §2.3、§6.4）
9. 界面变更：工作台新增**作业轨道**（固定件，非模块）；左侧菜单 8 项 → 9 项（"专题研究"升级为"作业"，新增"学习"）；工作面与学习区共享视觉体系，玻璃层级仍为三层（`designUI.md` §3）

## 取舍理由

- **不推翻已有视觉与地基**：D-011 的暗色玻璃、焦点带、模块系统、对话抽屉仍是有效资产；改动集中在"主导对象与入口层级"，避免重做设计系统
- **作业化而非对话化**：人的介入需要稳定宿主（阶段 / 产物 / 块），对话无法可靠定位与版本化
- **旁路而非审批**：本地单用户场景没有审批链，弹窗式协作会打断 agent 且不可回看；版本化 + 检查点是可测试的实现形态
- **交付物 → 验证性需求**：把"交付即终点"改成研究议程的生成器，数据库才能持续扩展并保持多元
- **学习区独立**：学习的信息密度与工作台差异大，独立布局更合适；仍共享视觉令牌与知识底座
- **保留对话能力**：时间线、后台运行、角标是已验证资产，降为接口之一而非删除
