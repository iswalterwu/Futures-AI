## 一、总则：全站一律黛驼，序列加墨做主线，红用茹藘，填色一律不透明

Walter 的要求（2026-10-01 / 10-02）：「不同图表应该切一下；季节图每条线颜色要分明、融合感强不突兀；其他图表颜色越简单越好，不要刺眼，
要能分清色阶；红是公司色，要融进大多数图表但不铺大面积；最大的一块不能是最刺眼的颜色；两色的图要分得开；整份报告要统一。」
10-02：「不应该有骐驎和朱，除了矿彩都是黛驼才对」「要包含这个样式的红色（茹藘），有红但不突兀」；看过序列图的三列对比后定「用墨 + 黛驼」。

- **全站只有一个色调：黛驼**（青雀头黛 · 茹藘 · 沙饧 · 吐绶蓝 · 苍艾 · 碧落 · 缥碧 · 窃蓝 · 驼褐，其他明月珰）。**不再有矿彩、骐驎、朱**。
- **序列**（季节图年份线与年份柱、2–4 条主次对比线、期限结构快照、单序列）：墨做主线（最新年 / 主序列 / Today），往后 茹藘 · 沙饧 · 苍艾 · 吐绶蓝 · 缥碧 · 碧落。
  模型线齐紫（不是数据色，只标「推演」）。
- **类目、十大区、分档、正负、热力格**：黛驼（§4、§6、§7、§8），同一页里同名同色。
- **红一律是茹藘**：序列里是上一年 / 次序列 / 1W；正负里是负；热力格里是减；类目里是第 2 名；十大区里是中国。
- **填色一律不透明**：只有三种例外允许半透明：5 年区间带（霜地 α .3）、事件 / 区间底色、卡上写明的「估计 / 弱信号」淡化（预测年、|z| ≤ 1 的弱柱；油轮页区级端点的轮廓填色，design:features.logistics.tankers#zone_endpoints，Walter 2026-10-13 点头）。
  按类目着色的堆叠里的估计期用白色斜纹、不淡化。
- **退役色**列在上面的 `palette-retired` 块里（不进 `palette-core`：体检把那个块里出现的每个色值都当核心色）。退役色上图由 chart_lint 报 ERR（规则 CK-RETIRED，实现中）；
  设计文档与技能散文里的 #hex 必须属于 palette-core ∪ palette-retired ∪ ui-tokens。

## 二、各图型

### 1. 年份线（季节图、累计图、年份柱、按年着色的散点）——序列

| rank | 位置 | 颜色 | 传统色名 | 线宽 |
|---|---|---|---|---|
| 0 | 最新年 | `#16191D` | 墨 | 2.6 |
| 1 | 上一年 | `#A35F65` | 茹藘 | 1.8 |
| 2 | 前 2 年 | `#BFA670` | 沙饧 | 1.4 |
| 3 | 前 3 年 | `#5A4B3B` | 苍艾 | 1.2 |
| 4 | 前 4 年 | `#4182A4` | 吐绶蓝 | 1.2 |
| 5 | 前 5 年 | `#80A492` | 缥碧 | 1.1 |
| 6 | 最老年（及更老） | `#AED0EE` | 碧落 | 1.4（对白只有 1.6:1，靠线宽补） |

- 年份多于 7 个时从 rank 2 起循环：`rest[(r − 2) % 5]`。不透明度一律 1.0。
- **5 年区间带**：霜地 `#C7C6B6`，透明度 0.3（图例色块 0.6）。**5 年均值线**：绍衣 `#A8A19C`，点线 1.0。
- 七色两两最小色差 ΔE2000 21.5（色盲模拟 12.6）；10-01 版矿彩是 27.6 / 17.0——换来全站一个色调，年份很多时区分度略低。

### 2. 多序列（几条序列并列比较，有主次）——序列

墨 → 茹藘 → 沙饧 → 苍艾 → 吐绶蓝 → 缥碧 → 碧落（与年份线同序）。需求 / 供给这类成对的量：需求 = 墨、供给 = 茹藘。
线图里的**类目线**（国家、炼厂、大区……）不是序列，跟着 §7 走，保证一名一色。

序列与类目同属黛驼，撞色按三条办（10-02 铺开时定，全站一致）：
1. **年份线不让**：上一年永远茹藘、前 2 年永远沙饧……，旁边卡里茹藘是负或是类目也不改（「红一律是茹藘」）。去年同月、LY 这类上一年线同此。
2. **其他序列线避让本节类目**：单条对比线、辅助线、右轴陪衬（Algonquin、P(开机)、DAP、气井气、桶数、中枢线……）按上面的顺序取，
   跳过本节类目、分档、正负已用的颜色。
3. **画成有正有负的柱（Δ、同比、变化量）时跳过茹藘**（零线两侧的茹藘柱会被读成负，同 §7 noRed）：例如平衡表季度节「分区对读」
   需求 Δ 墨 / 供给 Δ 沙饧；真实需求页价格同比柱沙饧。

### 3. 预测 / 模型

- **有母线的预测段**：母线自己的颜色画虚线，接在最后实绩点上，不带点。
- **没有母线的推演、模型、拟合**（下一年推演、模型路径、回归线、独立预测）：齐紫 `#6C216D`，原来是虚线的保持虚线。
- 情景线：Base 是实绩的延续时用母线色（墨）点线；其余情景按 §2 取色但跳过茹藘（同图上一年已占红），碧落排最后。多模型预报线同此。

### 4. 正负（按数值方向着色的柱、面积、z 条、发散色阶）——黛驼

正 青雀头黛 `#354E6B`，负 茹藘 `#A35F65`。**红只表示负**：图之外的表格数字、KPI、标签凡是按正负着色的，负也只能是红、红也只能是负；
按显示位取整后为 0 的数中性（不着色、不带正负号）。表格数字沿用界面的涨跌字色（正 `.up`、负 `.down`）。
发散色阶：负 茹藘 — 白 — 正 青雀头黛。

### 5. 期限结构快照——序列

Today 墨（带点）· 1W 前 茹藘 · 1M 前 沙饧 · 1Q 前 苍艾 · 1Y 前 吐绶蓝（点线）。按期限着色的一组曲线（M1、M3…）按 §2 取色，近端在前。

### 6. 十大区（类目，黛驼；按名字固定，柱、面积、饼、线、页签色点共用）

| 键 | 大区 | 颜色 | 传统色名 |
|---|---|---|---|
| NA | 北美 | `#354E6B` | 青雀头黛 |
| LATAM | 拉美 | `#AED0EE` | 碧落 |
| NWE | 西北欧 | `#4182A4` | 吐绶蓝 |
| MED | 地中海 | `#88ABDA` | 窃蓝 |
| FSU | 前苏联 | `#80A492` | 缥碧 |
| ME | 中东 | `#BFA670` | 沙饧 |
| AFR | 非洲 | `#5A4B3B` | 苍艾 |
| IN | 印度 | `#7C5B3E` | 驼褐 |
| CN | 中国 | `#A35F65` | 茹藘（十区里唯一一块红系） |

LPG 台 EA 七区：`EUR` = 西北欧色、`AP` = 亚太色，其余同名键照上表。大区按名字固定，优先于 §7-4：有正有负的分区堆叠里中国仍是茹藘（读图看图例；正负由零线上下和合计菱形表达）。十区两两最小 ΔE2000 10.1（色盲模拟 8.2）：美洲与欧洲是蓝灰、
其余是驼褐 / 绿灰，读图时成组。

### 7. 填色类目（堆叠柱、堆叠面积、饼；国家、炼厂、港口、船型、品种、部门……无先后）

类目色序：c1 青雀头黛 `#354E6B` · c2 茹藘 `#A35F65` · c3 沙饧 `#BFA670` · c4 吐绶蓝 `#4182A4` · c5 苍艾 `#5A4B3B` · c6 碧落 `#AED0EE`；
**其他 / 残差 / 未定** 一律明月珰 `#D4D3CA`。六色两两最小 ΔE2000 12.6。

取色规则（代码只有一份：`app.js` 的 `ftCatColors`，新页面经 `FTK.catColors` 调同一个函数）：

1. **排名**：同一类目族在本页所有图上的合计（不含「其他」）从大到小；量纲不可比时按第一次出现的顺序。第 1 名 c1、第 2 名 c2（茹藘）……按名次取色。
   所以大多数类目图都带一块茹藘，最大一块恒是青雀头黛。
2. **具名类目最多 6 个**，再多的小类目并进「其他」，卡上写明「其他含 …」。同一张图里不重用颜色。
3. **一名一色**：同一页里同一类目在每张图（含浮窗色签、图例、HTML 色块、表格色条）上同色。国家也是类目，不借大区色；大区色只给大区本身。
4. **有正有负的类目堆叠**（贡献分解、同比拆分这类 barmode relative 的图）跳过茹藘——茹藘在零线以下会被读成「负值」；
   调用 `ftCatColors(fam, { noRed: true })`，色序变成 c1、c3、c4、c5、c6。
5. **总量线和类目线同图**（全国 vs 各炼厂、EU27 vs 各国、合计 vs 各部门）：总量线当基准，用绍衣 `#A8A19C` 实线加粗。堆叠柱上的合计菱形用墨、白描边。
6. **阈值高亮**（如「渗透率 ≥30%」）不是正负、不用红：高亮 c1 青雀头黛，其余明月珰，卡上写明高亮口径。
7. 移动平均 / 12 月均这类叠在本序列上的平滑线用绍衣（同均值线）。
8. **有先后的分档**（停泊天数、租约年龄段、状态阶段）用黛驼深浅阶 `FT_CORE.ORD`：青雀头黛 → 吐绶蓝 → 窃蓝 `#88ABDA` → 碧落，近端 / 新的最深；
   「2010 前存量」这类兜底桶仍用明月珰。期限结构快照仍是 §5 的线色。

### 8. 季度表热力格——黛驼

同比、环比两张表都用「吐绶蓝增、茹藘减」：α = 0.55 × |Δ| ÷ 本节尺（封顶 0.55），增减两边同一把 α（两色明度相近；10-01 版给增格加深是按朱调的，已撤）。
按显示取整为 0 的格不着色。

### 9. 单条价差 / 单序列——序列

墨 `#16191D`。

### 10. 辅助元素（不是数据序列）

参照线、基准线、阈值线：绍衣 `#A8A19C`（点线或细线）；事件底色：绍衣低透明度。零轴、坐标轴、网格、白色描边照旧。

## 四、怎么定下来的（2026-10-01 → 10-02）

来历（摘自 2026-09-30 配色考古页，已归档 `design/Backup/Plans/PALETTE_ARCHAEOLOGY.html`）：
- 起点是 2025-06-25 存进 Excel 的个人图表模板（`AppData\Roaming\Microsoft\Templates\Charts`，73 个 .crtx）：三段式「最新黑加粗 / 上一期 `#C00000` / 更早浅色递淡」，年份比颜色多时都落在最淡一色，**不循环**。
- 2026-09-30 对站内 537 张图逐张审计：`#C00000` 有 307 张作上一期，另十几处被挪作 1W 前、供给、模型、「偏贵」等；琥珀 79 张里一半挪作类目色；
  正负配色至少 6 套（两套方向相反）；大区色 5 套并存。
- 之后：09-30 配色考古方案页 → 10-01 挑选台 44 色 → 10-01 S3「分图切换」→ 10-02「墨 + 黛驼」（下面 1–7 条）。

1. 10-01 上午：Walter 在配色挑选台从全站用过的 1314 色里逐位挑了 44 个，铺到全站（挑选台 10-04 已删，原件见 git tag `design-pre-consolidation-20261004`；挑选结果存在 Artifact 库）。
   教训：逐个位置单独挑的颜色凑在一起不成套——堆叠柱里藏青、宝蓝、纯黄、纯红挨着，刺眼。
2. 他嫌红太多 → 试「蓝在前、红殿后」→ 他说更丑 → 选回色序 C；随后指出问题不只是顺序，要按块数和块大小按需分配，并要求红作为公司色融进大多数图。
