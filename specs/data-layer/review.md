## 风险

- **上游数据陈旧**：东财库存日报最新数据 2025-12-31（上游停更）；发布检查会打印最新日期，但不会替用户判断数据是否可用
- **akshare 交易日历到期（有截止日）**：受测版本 akshare 1.18.63 的仓单静态交易日历止于 2026-12-31；此后仓单取数显式返回 validation_error（提示升级），不再静默 0 行成功。须在 2026-12-31 前升级 akshare、同步 `backend/constraints.txt` 并回归
- **上游 SDK 漂移**：akshare/EIA 以注入点与 HTTP 边界样本隔离；受测版本见 `backend/constraints.txt`（pyproject 仅声明兼容下界，升级须回归）；上游签名或字段变化需回归。akshare 内部请求无超时，已由适配器硬超时（300s）兜底，被放弃的挂起线程会存活到请求自行结束（不回写数据）
- **akshare 仓单实现依赖内置品种名表**：上游新增品种会让 `get_receipt` 整体崩溃（已实测 1.18.63 与 1.20.1）。已由上期所页面自解析绕过；页面改版时在线冒烟与 fixture 回归会同时失败，需更新品种名映射或解析
- **SDK 运行期打印与 serve 输出流**：akshare 仓单抓取逐日打印；按线程改道 stderr（含超时被放弃线程的迟到打印），查询与取数类命令的 stdout 只有结构化 JSON。serve 的启动信息（CLI 自打印一行）与 WARNING 及以上日志经 stderr；HTTP 访问日志与 uvicorn INFO 启动行已关闭（日志级别 WARNING），stdout 无运行期输出，托管进程无需排空 stdout，但须以探测端口判就绪
- **写进程启停过渡窗口**：任一持锁进程（serve 或 CLI 写命令）都提供只读通道；仅在其开库/目录重建与退出的短暂窗口内尚无端点，只读命令等待（≤30s），端点出现即路由、写锁释放即本地读取（单次路由的连接与响应体读取按剩余等待时间逐段约束；响应头/分块帧/Connection: close 的剩余边界见已知非阻断问题）；写命令退出时先排空在途只读请求（≤30s，超时强制停服）再关库；强制停服后通道线程可能短暂存活以完成剩余请求，关闭屏障保证它们不再访问已关闭的连接（独立 CLI 进程结束即回收）
- **进程间开库竞争**：只读命令在无写锁时本地短暂打开观测库；写进程取锁后开库遇占用会在 5s 内重试（取锁后新的只读命令不再本地开库），仍被占用（如外部工具长期打开观测库）则报“数据目录被其他进程占用”。占用的识别同时使用固定英/中文文本与当前系统错误码 32/33 的本地化消息（ctypes.FormatError），不依赖系统语言。外部进程无写锁长期占用时，只读命令约 2s 提前报占用。写锁文件删除在重试 2s 后仍失败时，写命令会以 internal 结束并遗留含本进程 PID 的锁文件（进程退出后按陈旧锁自动回收）
- **只读通道降级（极少见）**：CLI 写命令的只读通道启动失败或端点文件写不进时，写命令照常执行并在 stderr 提示；其间其他进程的只读命令回退为等待写锁释放（≤30s）
- **凭证显式传参（风险接受项，Gate 2 已接受）**：`config credentials <name> <secret>` 仍允许脚本化显式传入，可能留在 shell 历史/进程参数；推荐省略 secret 走不回显交互输入（CLI 帮助已提示）
- **mcp SDK 版本**：锁定 `mcp>=1.2,<2`（FastMCP API）；升级需迁移评审
- **多进程边界**：锁/只读路由的已知竞态已覆盖（陈旧锁、拒绝访问、删除失败与共享冲突重试、DuckDB 文件占用的两种消息变体、读写开库竞态、关闭屏障）；生产以真实子进程回归守护
