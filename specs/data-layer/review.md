## 风险

- **上游 SDK 漂移**：akshare/EIA 以注入点与 HTTP 边界样本隔离；受测版本见 `backend/constraints.txt`（pyproject 仅声明兼容下界，升级须回归）；上游签名或字段变化需回归。akshare 内部请求无超时，已由适配器硬超时（300s）兜底，被放弃的挂起线程会存活到请求自行结束
- **单写者固有限制**：非 serve 写命令（fetch/import/config）执行期间无只读通道（DuckDB 单写者）；只读命令等待其结束（≤30s），超时返回“写进程运行中，请稍后重试”
- **凭证显式传参（风险接受项，待 Gate 2 确认）**：`config credentials <name> <secret>` 仍允许脚本化显式传入，可能留在 shell 历史/进程参数；推荐省略 secret 走不回显交互输入（CLI 帮助已提示）
- **mcp SDK 版本**：锁定 `mcp>=1.2,<2`（FastMCP API）；升级需迁移评审
- **多进程边界**：锁/只读路由的已知竞态已覆盖（陈旧锁、拒绝访问、删除失败、DuckDB 文件占用）；生产以真实子进程回归守护
