# 工作台 v2 交互预览（Clarify 阶段）

这是根据用户查看首版工作台后的反馈制作的独立视觉原型，**不是已批准的正式前端实现**，不改变冻结的 `spec.md`、原工作台或后端。确认后再将规则融入规格、过 Gate 1 并修改正式组件。

## 本轮反馈与预览口径

- 正文由原版约 13px 增至 15px；模块标题 15px，表格 14px，数字用等宽；在信息密度与可读性之间保持一档区别。
- “一屏”暂定义为扣除侧栏、顶栏、焦点带及输入栏后的模块可用区；采用 4×4 基本网格：1/2 = 4×2，1/4 = 2×2，1/8 = 2×1，1/16 = 1×1。间隙在面积计算中扣除。尺寸可从每个模块标题栏切换；总面积超过一屏时模块区滚动，不压缩标准高度。
- 所有模块共用单行、同高度标题栏；标题、图标、信息、尺寸选择的位置一致。超出内容在模块内部滚动；简要说明单行，长文省略时可查看完整标题。
- 左侧栏折叠按钮固定在同一坐标；收起后只显示带名称提示的 SVG 图标，不用文字首字。
- 设置固定在侧栏左下角；主题按钮也在此，可直接切换浅色/深色。设置面板另提供系统跟随与界面点睛色；行情涨跌语义不随点睛色变动。
- 快讯单条展示并向上切换，带上一条/下一条与暂停控制，不做横向跑马灯。
- 每个行情数字附近提供迷你线图；曲线在原型中只示意展示方式，正式图型待用户决定。
- 所有数据是示例，页面明确标记。positions 与文档列表仅是占位示意，不读取真实账户或文档；对话抽屉是交互示意，不调用模型。

## 文件与运行

`index.html` / `style.css` / `app.js` 为原型源文件。`fixtures/*.json` 直接从 `frontend/src/contracts/mock/fixtures/` 复制，不手改复制件；更换示例数据时从源目录重新复制。

可用现有 Python 静态服务预览：

```text
python -m http.server 5174 --bind 127.0.0.1 --directory specs/frontend-workbench/assets/workbench-v2
```

打开 `http://127.0.0.1:5174/`。原版仍在 `http://127.0.0.1:5173/workbench`。

此处无框架、无新增依赖、无网络数据源。浏览器仅请求同目录的静态文件。
