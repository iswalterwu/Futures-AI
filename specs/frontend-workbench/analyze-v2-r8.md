## 内部发现

### F-01（P2）：T-V2-01 标准 4 测不出 G-02 的改动，plan §7.14 说“防回退”与事实不符

- **为什么测不出**（按令牌数值算）：
  - 字号 `type.nav` = 12.5px，每项左右内边距共 2×`space.grid_gap` = 24px。
  - 九项共 23 个汉字，总宽约 23×12.5 + 9×24 ≈ 504px。
  - 960 宽时窄窗导航可用宽度 = 960 − 2×26（`content_pad_x`）= 908px；979 宽时为 927px。
  - 所以 v1 的 `flex-wrap: wrap` 也只排成一行。
- **结果**：T-V2-01 删掉研究子项后，就算不改 CSS，标准 4 的断言也会通过：
  - 九项 `top` 相同（几何同一行）；
  - `overflow-x` 为 `auto`：v1 的 `.rail-navigation { overflow: auto }` 本来就使计算值为 auto；
  - “有溢出才检查滚动”和“滚到末端最后一项可见”两条，因为没有溢出，实际上不会触发；
  - 文档无溢出。
- **不准确的表述**：
  - plan §7.14 写“T-V2-01#4 用几何断言防回退为换行”，在令牌宽度下不成立；
  - §7.11 AC-002-6 的 S0 栏写“内部可横滚”，没有说明这是“空间不足时”才会发生；
  - §7.4 说“实现只补第三环”，但 `overflow: auto` 其实已经存在。
- **影响**：G-02 本轮的核心设计（`nowrap` 单行）没有任何自动化证据。验证命令 4 可能误放行没做完的实现。AC-002-6 本身（文档无溢出）不受影响。
- **最小修正**（只改文字，命令和矩阵不变）：
  1. T-V2-01 标准 4 和修改范围中的 `shell.spec` 新增用例：在 960 / 979 下增加计算样式断言，`.rail .nav-list` 的 `flex-wrap` 为 `nowrap`，`.fixed-link`（或其标签）的 `white-space` 为 `nowrap`。写法与 `breakpoints.spec` 现有的 `toHaveCSS('display','flex')` 相同，不加 JS、状态或令牌。
  2. 在标准 4 中写明：在令牌宽度下，“同一行”和“`overflow-x: auto`”用 v1 CSS 也能满足，只算行为证据；溢出相关的两条是条件分支，九项放得下时不会触发。
  3. plan §7.14 改为“用计算样式 `nowrap` 防回退为换行，几何与文档无溢出作行为证据”。§7.11 AC-002-6 的 S0 栏同步改为“空间不足时内部横滚”。§7.4 可以顺带说明 `overflow: auto` 已存在，新规则只加在窄窗选择器上。
  4. 修正后复跑只读 Analyze。

### F-02（P3）：M-09 的人工验收项在 960 宽度下观察不到

- **问题**：plan §7.12 的 M-09 和 T-V2-02 的修改范围写的是“窄窗（960）下九项单行、在导航内部横滚”。按 F-01 的计算，960 宽时不会出现滚动，验收人看不到“内部横滚”，可能误判为不通过，也可能为了看到横滚去人为制造溢出。
- **最小修正**：两处改为：“窄窗（960 / 979）下九项单行，页面不横滚；只有空间不足时才在导航容器内横滚（令牌宽度下放得下，不出现滚动条属正常）”。

### 观察（不计入判定）

- **O-1**：Plan 写了“纵向不滚”。但 `overflow-x: auto` 配 `overflow-y: visible` 时，`overflow-y` 的计算值会变成 auto，基础样式也已是 `overflow: auto`。单行时实际没有纵向溢出，所以这条只是说法问题。建议实施时把新规则全部限定在 `.rail[data-viewport-collapsed='true']` 下，不影响宽屏的纵向导航；如果确实要禁止纵向滚动，就写 `overflow-y: hidden`。
- **O-2**：“导航项 `flex: none`”真正的 flex 子项是 `.nav-list > li`，不是 `.fixed-link`。`.nav-link` 带 `overflow-wrap: anywhere`，真正起作用的是 `white-space: nowrap`：有了它，`li` 的自动最小宽度就是整段文字宽度，`flex: none` 写在哪里结果都一样。
- **O-3**：“最后一项矩形落在容器可视矩形内”的断言建议留约 1px 容差，避免亚像素误差。
- **O-4**：`checklist-v2` 的 C-01（已勾选）写的是“< 980 九项换行不溢出”，R3-O01 也是 G-02 裁定前的历史记录。这些由 A R4 在自己的产物里明确取代，实施者不改清单。
- **O-5**：§8 中 V2-S14 行的“已满足的闸门 1 / 2 / 4”是 `e84ee27` 时的措辞，已被 §3 的当前说明（闸门 2 / 4 对 G-02 增量重新打开）取代，不算问题。
