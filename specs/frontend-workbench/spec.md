## 1. 背景与动机（why）

- 本 feature 的 v1 为用户每天打开的界面建立地基：设计系统、导航/布局/路由、工作台与模块系统、对话抽屉与 CoT 时间线、图表暗色主题、与后端隔离的数据访问契约。前端正在独立分支实施，已有脚手架、令牌、契约/mock 与应用外壳，不再是零代码状态。
- D-016 已把产品主导对象升级为“作业”，模块工作台负责“看”、作业负责“做”，对话是接口之一。v1 的八项菜单、专题研究动态子项、仅“焦点带 + 模块”的首页需要回流 Clarify，不能直接以实施补丁绕过 Gate 1（主线 `docs/interaction.md` §2.4/§7、`docs/designUI.md` §3）。
- v2 只补**壳层入口与上下文**：九项导航、固定作业轨道、全局投放入口、作业/阶段对话上下文。作业列表/详情、采集/处理/分析/交付工作区与编辑行为由 `workbench-interaction` 交付；不在壳中重复实现。D-011 / D-015 的设计令牌、模块系统、行情取色、后台运行与时间线能力保留。
- 交付继续由可替换的类型化契约 + mock 驱动，不接真实后端或 pi。`data-layer` 不提供面向前端的 HTTP API；真实契约实现归 `api`，不构成本 feature mock 验收的前置。

## 2. 目标与非目标

### 目标（what）

- **设计系统**：界面令牌（色、玻璃层级、字体三族、字号阶梯、间距、圆角、层级）单一来源；从 FTEngine UI 规范资产按需移植并做暗色适配；代码只引令牌，不写字面量
- **应用外壳**：加载页 → 工作台；左侧九项固定菜单、顶栏（资讯 ticker + 数据源状态 + 全局投放）、内容区路由；侧栏可收起；窄窗口行为
- **工作台**：今日焦点带（固定顶部，承载当日日报核心结论与数字，点击展开完整日报）+ 作业轨道（固定件，非模块）+ 模块栅格
- **模块系统**：模块库（v1 七个模块）、固定栅格、添加/移除/排序（无拖拽）、布局持久化；统一模块壳（标题/副标/右注/状态徽/AI 角标/空态）
- **AI 对话**：底部固定输入栏 → 向上展开抽屉；CoT 时间线，每步可展开；运行中可切走页面、agent 后台继续；模块角标（运行中/完成）；agent 可引导跳转到模块；消息与事件可带作业/阶段上下文，抽屉显式展示，mock 回放不丢失上下文
- **图表暗色主题**：由令牌生成图表主题并注册；黛驼体系暗色亮化版；退役色不得出现；至少一张样例图在模块中渲染
- **数据访问契约**：前端所需数据与事件全部经一层类型化契约访问；mock 实现与真实实现可切换；契约文档化，供后端 `api` feature 实现；与 `workbench-interaction` 共用作业数据，不另造一套壳层作业状态
- **规范资产移植登记**：本 feature 用到的 FTEngine UI 条目搬入 `design/ui/`，保留原条目 id 与"为什么"，并登记暗色适配差异
- **质量守卫**：令牌对拍、字面量扫描、结构契约检查、组件/端到端测试、人工验收清单

### 非目标

- 真实后端对接（网络客户端实现、鉴权、令牌）：归 backend `api` feature；本 feature 只定契约 + mock
- Electron 桌面外壳、托盘、通知、打包（desktop-shell feature）；本 feature 在浏览器中验收
- 图表模板库（14 种 kind、chart-spec 编译、两级浮窗、复制/截图/水印、CK 体检规则）：归 chart-templates feature；本 feature 只做主题与一张样例图
- 日报、价格、平衡表、物流、格物致知、知识库、设置各页的实际内容与功能（各自 feature）；本 feature 只提供路由与占位页
- 作业列表/详情、四阶段页面、投放表单与抽取预览、介入/版本/交付物编辑与定稿（`workbench-interaction`）；本 feature 只做导航、工作台轨道、全局投放挂载与对话上下文接线。未集成时作业路由可显示明确归属的占位，不能把占位当成集成 AC 通过
- 验证队列、真实验证提醒、学习会话（格物致知）、协议蒸馏与知识写入闸门（后续 feature）；格物致知入口本轮仅占位
- 七个模块的真实数据与完整交互（各 domain feature）；本 feature 按 Q-001 裁定的深度做 mock 内容
- 亮色纸底主题与导出/打印映射（随日报导出 feature）
- 自由拖拽布局、用户自定义图表属性（v2）
- 多语言、移动端、无障碍专项

## 3. 需求条目

### R-001 设计系统与令牌

- **what**：
  - 界面令牌只有一处权威登记：色彩（背景渐变、玻璃面/边/模糊、文字三级、点睛红、琥珀、涨跌专色、状态色）、字体三族栈、字号阶梯、间距三档、圆角与例外、层级 z。数值来自 designUI.md §2 与 FTEngine UI 条目（Foundations / Colors / Fonts / Layout）的暗色适配版；散文与代码只引令牌名
  - **玻璃层级限三层**：焦点带 / 模块 / 抽屉；不得出现第四层玻璃面
  - **字体三族分工**沿用 FTEngine DNA（Q-019）：衬线用于品牌字标、页标题、KPI 大数；无衬线用于正文、导航、按钮、表格文字与模块壳标题；等宽用于 KPI 大数以外的一切数值、代码、单位、ticker（KPI 大数是"数值等宽"的唯一例外）；等宽数值一律等宽数字对齐，表格与卡内数值右对齐
  - **色语义**：涨跌专色（涨 `#C98A8F` / 跌 `#8FB8A4`）只用于登记的行情语义位置（D-015）——行情价格模块、关注列表（Q-015）与焦点带"行情"段（Q-016）——只涂字色不涂底；分析类元素保持"红 = 负/减"；界面点睛红与琥珀（= 非实绩 / 可编辑 / 待更新）的语义沿用 FTEngine Foundations；退役色（朱 / 骐驎 / 群青 / 石绿 / 茈藐）禁用
  - **空与零**：空值铺 en dash；差值带正号；按显示位取整为零的数中性——不着色、不带号、不印负零
  - **双语层级**：中文为主标题，英文以全大写小字号加宽字距作副标伴随（推断沿用 FTEngine，见 Q-008）
- **验收规则**：
  - [ ] AC-001-1 令牌登记与运行时样式对拍：登记的每个令牌在运行时样式/主题中存在且值相等（自动测试）
  - [ ] AC-001-2 代码零未登记色值字面量：静态扫描前端源码（样式与脚本）中的颜色字面量，命中即失败；规则与阳性/阴性样例随实现提交，阳性样例须命中
  - [ ] AC-001-3 玻璃层级 ≤ 3：静态检查只允许三个登记的玻璃层级被引用；整页截图层次清楚（人工验收）
  - [ ] AC-001-4 字族分工与数值规则：组件测试断言 KPI 大数为衬线、模块壳标题与正文为无衬线、其余数值为等宽且等宽数字对齐与右对齐（Q-019）；格式化函数单元测试覆盖 en dash / 正号 / 零中性 / 负零
  - [ ] AC-001-5 涨跌色只用于行情语义且只涂字色：静态检查涨跌令牌的引用范围限于登记的行情语义位置（行情价格、关注列表、焦点带行情段，D-015）且只用于字色、不用于背景；分析类元素引用"红 = 负"令牌（组件测试）
  - [ ] AC-001-6 退役色不出现在令牌、主题与源码（静态扫描）

### R-002 应用外壳与导航

- **what**：
  - **启动**：加载页（显示加载进度与通知文案）→ 就绪后进入工作台；两者之间无空白闪屏；启动失败时加载页显示原因并可重试（Q-021）；直接打开某个页面地址时，就绪后停留在该页面，不跳回工作台
  - **左侧菜单固定九项与顺序**：工作台 · 作业 · 日报 · 价格 · 平衡表 · 物流 · 格物致知 · 知识库 · 设置；“专题研究”不再单列，保留为作业类型。当前项有明确指示；格物致知及其他 domain 页为占位页（文案注明归属 feature）
  - **作业入口**指向稳定地址 `/jobs`，列表/详情由 `workbench-interaction` 提供、由共享 mock 作业驱动；原专题研究动态子项不另行保留。壳单独验收时作业地址为归属明确的占位；集成后同一入口进入真实 mock 列表/详情，作业详情仍高亮“作业”导航项。格物致知占位地址为 `/learning`（路由不改，D-018 §5）
  - **顶栏**：资讯 ticker（滚动的新闻条目）+ 数据源状态（各源新鲜度与待更新点）+ 全局“投放”按钮；资讯与数据源状态经契约取 mock
  - **全局投放**：任意页面可打开同一个非阻塞采集抽屉；壳负责入口与挂载，投放内容和流程归 `workbench-interaction`。作业内打开时携带当前作业上下文；关闭回到原页面，不中断后台运行
  - **侧栏可收起/展开**，状态持久化（刷新后保持）
  - **窄窗口**（Q-004）：设计基准 1440×900；断点沿用 FTEngine 登记值——窗口窄于 980 时侧栏塌成顶部横向导航；模块栅格列数在 980 / 1400 / 1500 处变化，焦点带数字卡数量在 1240 处变化（Q-018）；最小支持宽度 960；任何支持宽度下不出现横向页面滚动条
  - **路由可直达**：每个菜单项有稳定地址；刷新后停留在当前页
- **验收规则**：
  - [ ] AC-002-1 加载页 → 工作台（端到端：加载页出现、就绪后工作台出现，无空白帧）
  - [ ] AC-002-2 菜单九项与上述顺序一致，不再单列专题研究；逐项点击地址与当前项一致，格物致知占位注明归属；直接打开非工作台地址并刷新仍停留，作业详情高亮“作业”（端到端；作业详情部分为跨 feature 集成验收）
  - [ ] AC-002-3 作业入口对应的列表由共享 mock 作业驱动：mock 增加一项 → 经作业入口可见并可进入对应作业；不依赖旧专题研究动态子项（端到端，列表/详情由 workbench-interaction 提供，跨 feature 集成验收）
  - [ ] AC-002-4 顶栏 ticker 与数据源状态渲染 mock 数据；状态点语义（新鲜 / 待更新）取令牌；“投放”按钮可见且有明确文案（组件测试）
  - [ ] AC-002-5 侧栏收起/展开持久化（端到端：收起 → 刷新 → 仍收起）
  - [ ] AC-002-6 窄窗口断点行为（端到端：在 980、1240、1400、1500 上下各取一个视口，并取最小宽度 960 与基准 1440×900，断言侧栏形态、模块栅格列数、焦点带数字卡数量、文档无横向溢出）
  - [ ] AC-002-7 加载页显示加载进度与通知文案；启动失败时显示原因与重试，重试成功后进入工作台（端到端，Q-021）
  - [ ] AC-002-8 工作台、作业列表/详情及其他菜单页的顶栏“投放”进入同一个采集抽屉；作业内带当前作业上下文；关闭后路由不变、后台 run 不重启（端到端，跨 feature 集成验收；不以空按钮/占位代替流程）

### R-003 工作台、今日焦点带与作业轨道

- **what**：
  - 工作台首页 = 顶部今日焦点带 + 作业轨道 + 模块栅格；焦点带与作业轨道均固定（不可移除、不进模块库），作业轨道位于焦点带和模块区之间，不新增玻璃层级
  - **作业轨道**：进行中作业的紧凑卡片，显示作业名、类型、按提取 → 处理 → 分析 → 交付顺序的阶段进度与待介入角标；状态用文案/图标区分，不只靠颜色。数据来自与作业列表/详情相同的契约 mock，点击进入对应作业的当前阶段；不在壳层自行推进阶段或维护第二套状态
  - 轨道有加载 / 无进行中作业 / 错误三态；空态说明原因并提供作业入口，错误态含可复制诊断；状态与角标随契约结果刷新。真实验证提醒后置，本轮不伪造验证队列功能
  - 焦点带内容：当日日报的核心结论（若干条）+ 关键数字（含方向与变化量），经契约取 mock；点击展开完整日报（v1：跳转日报占位页并携带当日标识）
  - 焦点带中每个数字在契约里**声明语义**（行情 / 分析），按语义取色：行情用涨跌专色，分析用"红 = 负"；数字遵守 R-001 数值规则
  - 焦点带分"行情 | 指标"两段（Q-016，D-015）：行情段只放行情语义数字，指标段只放分析语义数字，两段在视觉上分隔，同一个红色不在相邻数字卡上表示相反含义
  - 无当日日报时显示空态并说明原因（如"今日日报尚未生成"），不留空白
- **验收规则**：
  - [ ] AC-003-1 焦点带渲染 mock 日报摘要：结论条目、数字、方向色（组件测试）
  - [ ] AC-003-2 点击焦点带跳转日报页并携带当日标识（端到端）
  - [ ] AC-003-3 无日报时显示空态文案（组件测试）
  - [ ] AC-003-4 数字按声明语义取色：行情语义用涨跌色，分析语义用"红 = 负"（组件测试）
  - [ ] AC-003-5 焦点带分"行情 | 指标"两段：行情语义数字只出现在行情段、分析语义数字只出现在指标段，涨跌专色只出现在行情段（组件测试 + 人工验收，Q-016）
  - [ ] AC-003-6 焦点带固定：不可移除、不出现在模块库中，模块布局变更不影响焦点带（端到端，Q-021）
  - [ ] AC-003-7 作业轨道按共享 mock 数据显示作业名/类型、固定顺序四阶段进度与待介入角标；运行中/待人工确认/冲突不只靠颜色；更新 mock 后轨道与作业列表一致，点击进入对应作业当前阶段（组件测试 + 端到端，跳转及一致性为跨 feature 集成验收）
  - [ ] AC-003-8 作业轨道始终位于焦点带与模块区之间，不出现在模块库、没有移除/排序入口；模块增删/排序与刷新均不影响它（端到端）
  - [ ] AC-003-9 作业轨道的加载/空/错误三态可触发，空态有原因与作业入口、错误态诊断可复制；不影响焦点带与模块区独立展示（组件测试）

### R-004 模块系统

- **what**：
  - **模块库 v1 七个模块**：行情价格、库存/供需指标、物流在途、当前头寸、文档目录、关注列表、数据发布日历；每个模块有唯一 id、名称、说明、默认尺寸档位（栅格跨列数）
  - **固定栅格**：列数由断点登记决定（Q-004）；模块按顺序填入；用户可从模块库添加（追加到末尾）、在模块壳上上移 / 下移 / 移除；不做拖拽（Q-005）
  - **模块库**列出全部七个模块并标明是否已在工作台；不在工作台的可添加

### R-005 AI 对话抽屉与 CoT 时间线

- **what**：
  - **底部固定输入栏**在任何页面可见；提交后抽屉向上展开覆盖内容区下部（两档高度 + 收起，推断见 Q-009）；抽屉是第三层玻璃
  - **时间线**：每次 agent 运行用时间线呈现——步骤类型包括思考摘要、工具调用、工具结果、文本输出、完成、失败；每步可展开看详情（推理全文、工具参数与结果摘要）
  - **后台运行**：运行中用户可切换页面或收起抽屉，运行不中断；回到抽屉时状态连续；输入栏显示运行中指示
  - **模块角标**：事件声明关联模块时，该模块壳显示角标（运行中 / 完成），用户查看后清除
  - **引导跳转**：事件可携带"建议跳转到模块/页面"，时间线出现可点击入口，点击后导航到目标并高亮模块；目标模块不在工作台（已被移除）时，提示"该模块不在工作台"并提供"添加回工作台"，不自动改变布局；目标不存在时提示且不跳转（Q-020）
  - **事件流契约**：定义事件类型集合与字段（会话 id、步骤 id、类型、时间、模块关联、文本 / 工具摘要、终态）；mock 以脚本化回放提供，至少覆盖成功、失败、长时间运行三种脚本
  - **作业上下文**：`SendMessage` 与 agent 事件可带可选 `jobContext`（作业 id / 阶段）；作业内发送时透传，抽屉展示当前输入及各 run 发起时的作业/阶段标识。阶段切换或离开页面不改写已有 run 归属；离开作业后的全局发送不沿用上一作业。可按作业查看其事件，不把其他作业或无上下文的事件误标为当前作业
  - 未带上下文的 v1 消息与事件继续有效，既有时间线、模块角标、后台运行与唯一终态语义不变；上下文不赋予 agent 自行推进阶段或覆盖产物的能力，结构化介入写路径归 `workbench-interaction`
- **验收规则**：
  - [ ] AC-005-1 输入栏全局可见；提交后抽屉展开并显示用户消息（端到端）
  - [ ] AC-005-2 时间线渲染 mock 事件流：步骤可展开/收起，终态（完成 / 失败）显示（组件测试）
  - [ ] AC-005-3 运行中切页或收起抽屉不中断（端到端：开始运行 → 切到其他菜单 → 返回，以及收起抽屉 → 重新展开，两种情况下时间线都包含期间产生的步骤，同一次运行未重启、步骤不重复；Q-021）
